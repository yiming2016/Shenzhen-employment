# 深圳社保成本计算器

桌面 EXE 版，目前只包含社保（养老、医保、生育、失业、工伤、公积金），不含税务。

## 目录结构

```
core/                核心计算逻辑（纯 TypeScript，零依赖）
  params.ts          政策参数表：费率、基数上下限、行业费率、来源链接
  engine.ts          计算引擎：一个纯函数 calculate(input, params)
  types.ts           类型定义
desktop/             桌面端（Electron + Vue 3）
  main.js            Electron 主进程：窗口、参数文件读写
  preload.js         安全的桥接层
  src/               Vue 界面：试算页、政策参数编辑页、说明页
tests/               单元测试（对照 Excel 数值）
release/             打包输出（便携版 EXE）
```

## 常用命令

- `npm test`：编译核心并运行单元测试
- `npm run dev`：启动 Vite 开发服务器（配合 `npx electron .` 开发调试）
- `npm run build`：编译核心 + 构建界面
- `npm run start`：构建后在本地运行 Electron
- `npm run dist`：打包为 Windows 便携版 EXE

## 启动速度说明

- **绿色目录版（release/win-unpacked/深圳社保计算器.exe）**：免安装、免解压，启动约 2 秒，日常使用推荐。
- **便携版（portable.exe）**：每次启动都要先解压到临时目录，约 8~10 秒，适合拷贝到 U 盘随身携带。
- **一键更新绿色版.bat**：自动关闭旧进程 → 重新构建 → 更新绿色目录，双击即可。

以后每次修复都会直接重建绿色目录版，无需手动安装。

## 为什么这样设计（为手机 App 铺路）

所有计算规则都在 `core/` 里，是纯 TypeScript 参数驱动代码：

1. 计算函数不碰任何 DOM / Node API，手机端可以直接复用；
2. 政策参数（费率、基数）集中在 `params.ts`，改政策只改数据不改逻辑；
3. 界面（desktop/）只是壳，以后做手机 App 时把 `core/` 复制过去即可。

## 计算规则（与 Excel 一致）

- 养老基数 = 工资限制在 [4775, 27549]
- 医保基数 = 工资限制在 [6733, 33666]
- 生育基数 = 与医保相同
- 失业基数 = 工资限制在 [2520, 574101]
- 工伤基数 = 工资（不设上下限），费率按行业 1~8 类
- 公积金基数 = 工资，默认比例 5%
- 深户职工医保默认一档（个人2%/公司6%），非深户默认二档（0.5%/1.5%）
- 灵活就业只缴养老（深户21%/非深20%）、医保（8%）、失业（1%）

## 已知差异

原 Excel 第 6 档样例（工资 45000）把失业缴费基数直接写成了上限 574101，
即使 45000 低于上限。本程序按通用规则实现：工资低于上限就按工资缴费，
只有工资 ≥ 上限时才按下限/上限封顶。如需完全照抄 Excel 的行为，可在
`core/engine.ts` 中调整失业基数规则。
